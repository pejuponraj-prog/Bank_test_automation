# Copilot instructions
This is a test automation project for a demo bank.


-Use Python, Playwright(sync API) and pytest.
-Use Page Object Modal. Page Classes are in pages/, test are in tests/.
-Follow the style of pages/login.py.
-Do not put assertions in page classes. Use expect() in tests.
-Use base_url from pytest.ini. Use paths like "/accounts".
-Never write real passwords or secrerts in the code.
-Keep code simple.
